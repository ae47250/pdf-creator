# Pinned Open Sans font for A-BASIC-01

`OpenSans-latin-wght-v44.woff2` is the official Google Fonts Open Sans v44
Latin variable WOFF2 returned for both the 400 and 700 requests. It supports
the fixture's 400 regular and 700 bold weights from one file, so one file is
smaller and avoids duplicating identical bytes.

- Family: Open Sans
- Version: v44 Google Fonts webfont distribution
- Weights used: 400 and 700
- Upstream CSS source: `https://fonts.googleapis.com/css2?family=Open+Sans:wght@400;700&display=swap`
- Upstream WOFF2 source: `https://fonts.gstatic.com/s/opensans/v44/memvYaGs126MiZpBA-UvWbX2vVnXBbObj2OVTS-muw.woff2`
- Font SHA-256: `d8e4fe0452aa2076429a9bb5d8757d00a994dd95986cf950e9a1a371b9a072a0`
- Font bytes: 48,320
- License: SIL Open Font License 1.1; see `OFL.txt`.
- License source commit: `googlefonts/opensans@bd7e37632246368c60fdcbd374dbf9bad11969b6`
- License SHA-256: `01cd5ffb3a528c219a86e49a814c6c53bd8a69b9a3c305dd237074ba1c811af7`

The fixture embeds this exact file as a `data:` WOFF2 URL. It makes no runtime
font request. The separate local copy exists for license, version, and hash
review; the integrity test proves that the embedded bytes match it.
